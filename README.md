# Afterglow — Sunrise & Sunset (East Coast)

Welcome page with two modes:
- **Sunrise** — east-facing viewpoints (Atlantic beaches, piers, Cadillac Mtn, Fort Monroe, VA Beach, Lake Worth/Palm Beach…), scored for that morning; sky preview rises in the east (blue hour → dawn glow → sunrise → golden hour).
- **Sunset** — west-facing viewpoints (bays, sounds, Gulf), scored for that evening; sky preview sets in the west.

Each spot opens a forecast-driven sky render (WebGL, NOAA HRRR/GFS cloud layers + GOES/CAMS aerosol) with a time slider and Play button. It is a forecast visualization, not a photo.

Separate from the original canvas app at https://stoneridgeclothingco.github.io/afterglow-sunset/
